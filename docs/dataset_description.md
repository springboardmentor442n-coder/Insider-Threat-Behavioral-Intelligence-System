# Dataset Description

## Project

Insider Threat Behavioral Intelligence System

## Dataset

CERT Insider Threat Dataset v4.2

## Dataset File

logon.csv

## Dataset Overview

The logon dataset contains employee login and logout activities collected from an enterprise environment.

Each record represents one authentication event.

## Columns

| Column | Description |
|---------|-------------|
| id | Unique event identifier |
| date | Login/Logout timestamp |
| user | Employee ID |
| pc | Computer ID |
| activity | Logon or Logoff |

## Dataset Statistics

- Records : 854,859
- Features : 5
- Missing Values : 0
- Duplicate Records : 0

## Objective

This dataset will be used to analyze employee login behavior and build an Insider Threat Detection System.
