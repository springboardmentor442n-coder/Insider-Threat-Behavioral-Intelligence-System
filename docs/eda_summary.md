# Exploratory Data Analysis Summary

## Key Observations

- The dataset contains more Logon events than Logoff events.
- Employee activity peaks during standard office hours.
- Approximately 30% of events occur after working hours.
- Weekday activity is significantly higher than weekend activity.
- Some users and computers generate much higher activity than others.

## Conclusion

The exploratory data analysis provides useful insights into employee behavior and establishes a strong baseline for future insider threat detection models.
