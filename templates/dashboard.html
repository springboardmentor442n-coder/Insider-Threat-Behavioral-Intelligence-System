Methodology

This system uses an XGBoost classifier trained on 330,452 real user-day records from the CERT r4.2 insider threat dataset. Unlike threshold-based labeling approaches, ground-truth labels here were matched at the individual log-row level against CERT's official answer files — ensuring the model learns genuine behavioral patterns rather than re-deriving arbitrary rules. The train/test split is performed by user identity (not by date) to prevent identity leakage. Model explainability is powered by SHAP (SHapley Additive exPlanations), providing a game-theoretic breakdown of each prediction.

Validated performance: PR-AUC 0.40, user-level recall 19/20 on a fully held-out set of never-seen users.
